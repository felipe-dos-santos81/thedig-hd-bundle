========================================================================
6. CORRECTIONS VS THE TASK BRIEF
========================================================================
1. LOFF is 111 records of (u8 room, u32LE offset), not 110 records of
   (u32LE offset, u8 kind). The brief's 'u16LE header 367' is the u16LE
   read of count(0x6f=111) + first room(0x01): 0x016f = 367. The
   brief's 'kinds 2..111' are the room numbers shifted by one byte.
2. There are 111 rooms (1..111), not 110; the brief's stride missed
   room 111. Every per-room tag therefore counts 111.
3. Room chunk stride is next = start + size (header-inclusive, NO odd
   padding). The brief's + (size & 1) desyncs all 111 rooms; the
   correct stride desyncs 0.
4. OBIM/OBCD counts are 842/842 (one of each per object), not 841/239.
5. OBIM images are IMxx with x = 01..0E (state is 1-based); IM00 never
   occurs in OBIM. An IMxx payload is SMAP (492) or BOMP (150); the
   brief only listed SMAP.
6. RMIM IM00 payload is SMAP optionally followed by a ZP01 chunk; smaplen
   is the SMAP chunk size (header-inclusive), so it equals the IM00
   payload length only when no ZP01 follows (50/111 rooms).
7. NCD / XCD / LSC / SCR / BCD are NOT real room chunks: they are the
   1-byte-shifted tags read by the brief's padded stride. The real script
   chunks are EXCD, ENCD, NLSC and LSCR.
8. PALS holds 1..6 768-byte palettes (804 + 780*(N-1) bytes), not a fixed
   ~804-byte block with a single table.
